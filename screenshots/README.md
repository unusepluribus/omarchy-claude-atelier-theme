# Claude Atelier screenshots

Captured on 2026-09-06 from a real Omarchy desktop, not generated mockups. The PNG files are the original captures, including region captures for the bar and calendar.

- [Desktop](desktop.png): 3456 × 2160, two neutral Foot demo windows with a static TypeScript example and a palette specimen.
- [Floating bar](bar.png): 3456 × 152, optional Shibumi split-bar layout.
- [Workspaces](bar-workspaces.png): 880 × 152, optional Atelier workspace indicators.
- [Controls](bar-controls.png): 956 × 152, system controls with the drawer closed.
- [Calendar](calendar.png): 1580 × 1240, the Omarchy clock's calendar hosted by Shibumi.

The setup uses the Claude Atelier palette, Claude Quiet Graphite wallpaper, separately reviewed local blur/geometry/terminal settings, Shibumi 0.1.1-beta.11, and optional Atelier widgets. Terminal and code fonts were preserved. The demo editor uses isolated syntax styling; it is not an additional bundled editor theme.

Screenshots were staged on workspace 3. Window contents on workspaces 1 and 2 were excluded; their workspace indicators remain visible in the bar. No personal documents, account panels or drawer contents are shown. Capture-session scripts and machine state are not included.

Installing the theme alone does not install this bar, arrange windows or enable optional plugins. See the [installation and customization notes](../README.md#bar-and-optional-extras).
